O projeto foi feito usando conceitos básicos de Programação Orientada a objetos, de maneira simples, temos a classe Mídias, a classe mídias tem seus métodos normais e abstratos, e seus objetos, a classe Mídias é a classe mãe que fará com que as classes de midias verdadeira (Filme, Serie, Jogo e Livro) puxem informações da classe Mídia, todas as classes terão seus próprios atributos, a classe Filme tem o diretor e ator principal, a Serie tem a quantidade de temporadas, a Jogo tem consoles e a Livro tem o autor, a classe Mídias fica responsável por pesquisar sobre essas informações nas APIs, (As APIs usadas foram do TMDB, OpenLibrary, Twitch e TVmaze), depois de salvar os métodos, tem a classe Review, Lista e Usuário, a classe Review fica responsavel por salvar a review que o usuario fizer em determinado filme, com nota e comentario, assim a informação fica salva na midia, a classe Usuario fica responsavel por criar o usuario com o nome, e salvar quaisquer informações de midia, review e lista em determinado usuario, e a classe Lista, cria uma lista e salva da maneira que o usuario preferir, colocando as midias na lista, o arquivo interface fica responsavel para rodar isso na tela e salvar as informações como o usuario preferir.
Para o código funcionar, o usuário deve baixar a pasta completa com os arquivos interface mídia, midiaDudinha e review, a interface vai puxar todas as classes e funções desses arquivos e fazer funcionar
